# Higher and Lower Game

## Overview
The Higher and Lower Game is a fun and interactive way to test your guessing skills. Players will be given a range of numbers and must guess whether the next number drawn will be higher or lower than the previous one.

## How to Play
1. The game starts with a random number.
2. After each guess, the player is informed whether they were correct or incorrect.
3. The game continues until the player decides to quit.

## Features
- Random number generation
- User input handling
- Scoring system based on correct guesses
- Easy to understand and play

## Getting Started
To play the game, simply run the Python script in your command line or terminal. Follow the on-screen instructions to start guessing!
